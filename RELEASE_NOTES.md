# AI Native Platform v0.1.0

The first executable prerelease of the AI-native repository standard.

Highlights:

- profile-aware conformance for six product types;
- evidence-backed validation;
- installable CLI with JSON, SARIF, scoring, diagnostics, initialization, and migrations;
- complete fixture matrix;
- private reusable workflow distribution;
- bounded self-improvement;
- checksums, SPDX SBOM, and build provenance.
