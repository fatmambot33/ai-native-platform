# Contributing

## Workflow

1. Open a scoped issue with evidence and objective acceptance criteria.
2. Create a focused branch.
3. Update the contract, validator, tests, templates, and documentation together.
4. Run all checks listed in `AGENTS.md`.
5. Open a pull request and link the issue.

## Contract changes

A manifest change must include:

- JSON Schema changes;
- semantic-validator changes when JSON Schema is insufficient;
- passing and failing tests;
- template updates;
- changelog and migration notes;
- an explicit compatibility assessment.

## Pull requests

Keep pull requests small enough to review. High-impact changes require human approval and must not be auto-merged.
